# Examples

Worked examples of OCDS releases produced by the NZ-OCDS mapping pipeline.

## sample-release-ocds-nz-gets-11062705.json

A complete OCDS 1.1.5 release package for an awarded New Zealand government contract.

| | |
|---|---|
| OCID | `ocds-nz-gets-11062705` |
| Buyer | Ministry of Business, Innovation and Employment |
| Tender title | Economic Evaluation Panel |
| Suppliers | 5 (panel award — Motu, NZIER, McDermott Miller, Sapere, MartinJenkins) |
| Tender period | 2015-04-28 → 2015-05-12 |
| Awarded | 2015-07-03 |
| Source | GETS award notice + GETS supplier data + GETS UNSPSC categories |

This release passed the **OCDS Data Review Tool's structural checks** against `OCDS release package schema version 1.1`. The only items it flags are three intentional NZ-extension fields (`agencyTier`, `abbreviation`, and a `url` nesting issue) — see the [`extensions/` directory](../extensions) for the corresponding extension proposals.

## Validating yourself

Paste the contents of the JSON file into the [OCDS Data Review Tool](https://standard.open-contracting.org/review/) — it will run schema validation and render the release in OCP's reference visualiser.

## Provenance

This release is generated by a Python transform that reads from a wide composition table built upstream from the publicly available GETS data feeds (current and historical RFx, supplier, region, and category tables, plus the buyer master list). Each OCDS field traces back to a specific GETS source column via the mapping documented in [`mapping/`](../mapping).
