# NZ-OCDS Mapping

A draft New Zealand implementation profile for the [Open Contracting Data Standard (OCDS)](https://www.open-contracting.org/data-standard/) — built against the publicly available [Government Electronic Tenders Service (GETS)](https://www.gets.govt.nz/) data, anchored to the [NZ Government Procurement Rules (5th edition, 2025)](https://www.procurement.govt.nz/) and the [NZGP Approved Government Model Templates (A-GMTs)](https://www.procurement.govt.nz/templates/).

## Status

**Draft v0.4 — not endorsed by NZGP, MBIE, or the Open Contracting Partnership.** This work is independent civil-society implementation, prepared as evidence that NZ's OGP commitment [NZ0029](https://www.opengovpartnership.org/members/new-zealand/commitments/NZ0029/) is technically feasible at substantially less effort than its current 2030 timeline implies.

Open for review and comment via Issues.

## The core finding

**The NZ Procurement Rules already mandate the data OCDS expects.** Of 114 OCDS paths analysed in the v0.4 mapping:

- 23 Direct + 13 Derived = data flows from GETS today
- 19 Rule-mandated = required by law to exist (Rule 6's planning elements, Rule 32's contract-award fields, Rule 34's Contract Management System fields, Rule 36's prompt-payment publication, etc.) but not currently published structurally
- 14 Template-sourced = captured in mandatory NZGP Government Model Templates but not centrally published
- 31 NZ Extension fields (across 18 proposed extensions, each anchored to specific Rules + glossary entries)
- Small remainder of constants, vocab translations, and genuine gaps

So **80%+ of OCDS coverage closes by structuring data the Rules already require.** OCDS-NZ alignment isn't a new data-collection burden on agencies — it's a structured-publication layer over data the Rules already mandate to exist.

## How to use the spreadsheet

`mapping/ocds-nz-mapping-v0.4.xlsx` has eight sheets:

1. **README** — methodology, sources, change log
2. **OCDS Mapping** — 114 OCDS 1.1.5 paths × {GETS source, Rule reference, status, notes, NZ extension ID}. Status colour-coded.
3. **Vocab Translations** — 47 codelist translations between GETS values and OCDS controlled lists, each linked to the authoritative codelist file in [`open-contracting/standard 1.2-dev`](https://github.com/open-contracting/standard/tree/1.2-dev/schema/codelists).
4. **NZ Extensions** — 18 proposed extensions, each anchored to a specific NZ Procurement Rule and glossary entry.
5. **Rules Inventory** — all 47 NZ Procurement Rules with OCDS-relevance commentary.
6. **Templates Inventory** — 31 NZGP Approved Government Model Templates with OCDS-relevance commentary.
7. **Publishing Governance** — 8-step publishing process and 8 roles, NZ-localised from NSW Open Data Publishing Guidelines.
8. **Sensitivity Classification** — 14-row publish/redact/aggregate/suppress policy anchored to NZGP Rule 5, OIA 1982 s9, Privacy Act 2020.

## Regenerating the spreadsheet

The `.xlsx` file is generated by `mapping/build_ocds_mapping.py`. To regenerate:

```bash
cd mapping/
python3 build_ocds_mapping.py
```

Requires Python 3 with `openpyxl` installed (`pip install openpyxl`).

The build script is the source of truth. The `.xlsx` is a generated artefact convenient for non-coder review (OCP Helpdesk, Transparency NZ, etc.). When making changes, edit the script and regenerate — don't edit the `.xlsx` directly.

## Strategic context

NZ committed to OCDS alignment under [OGP commitment NZ0029](https://www.opengovpartnership.org/members/new-zealand/commitments/NZ0029/). As of mid-2026:

- IRM midterm review rates the work *"modest potential"*; mandatory fields *"yet to be determined"*; full implementation timeline 2030
- Only 5% of NZ government procurement spend is reported on GETS ($2.6B of $51.5B)
- Over 50% of published notices are missing contract values
- ~94% of emergency procurements are not published
- Civil society (Transparency International NZ, Office of the Auditor-General) has been publicly critical for years

This mapping is intended to fill the "mandatory fields TBD" vacuum with a working, defensible, Rules-anchored proposal — and to inform structured publication that delivers NZ0029 substantially ahead of schedule.
